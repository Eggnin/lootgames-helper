# LootGames Helper

GTNH 里 **LootGames** 小游戏（数独 / 扫雷）的客户端辅助模组：按一个键自动解题，另一个键开关提示。

- 数独：按 `K` 自动填完，四关连过
- 扫雷：按 `K` 自动解，四关连过
- 纯客户端模组，服务器不需要安装

## 环境

- Minecraft **1.7.10 + Forge**（GTNH 自带）
- **LootGames 2.2.2 或更新**（数独是 2.2.2 加入的）
- 客户端安装即可

## 安装

把 `LootGamesHelper-1.1.2.jar` 放进 `mods/` 文件夹，重启游戏。

## 使用

1. 走到棋盘旁边（数独 9×9、扫雷 13×13～19×19，棋盘就是脚下那层方块）。
2. 按 `K`：自动解**最近**的那个棋盘（数独还是扫雷会自动判断）。再按一次停止。
3. 按 `L`：开关棋盘提示。
   - 数独：空格显示绿色答案；**还没点到的格子会铺绿色方块**，填完就消失。
   - 扫雷：推断出的安全格标绿、雷标红。

按键可以在 **选项 → 控制 → LootGames 助手** 里改（默认 `K` / `L`）。

### 扫雷要跟着绿色走位

服务端只接受近距离的点击（几格以内），大棋盘站一个地方是够不到的。模组会先把能点的点完，
剩下够不到的格子会**一直保持绿色**，屏幕左上角和聊天栏也会提示"往东走 3 格"这类方向，走过去会自动继续。

## 配置

`config/lgsudoku.cfg`：

```ini
sudoku {
    I:cellsPerTick=3      # 每 tick 最多填几格数独
}
minesweeper {
    I:revealPerTick=6     # 每 tick 最多翻开几格扫雷
}
client {
    B:showHints=true      # 显示绿色提示
    B:showHud=true        # 左上角显示进度
    D:scanRadius=24.0     # 搜索棋盘的半径（格）
    D:reachBlocks=5.0     # 只点这个距离内的格子；够不到的会提示你走过去
}
```

## 注意

- 潜行中、打开界面时会自动暂停。
- 距离太远的格子不会乱点，会提示你走过去。
- 数独/扫雷的四关都会连续自动通过，奖励照常发放。
